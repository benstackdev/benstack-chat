# BenStack Chat
An whitelisted direct messaging web app for BenStack's community. This project is currently being created live on [YouTube](https://www.youtube.com/@benstackdev) and [Twitch](https://www.twitch.tv/benstackdev) in an effort to learn full stack web development.

## Project Status
### Complete
- Invite-only sign-up with basic RBAC using [better-invite](https://www.better-invite.com/)
- Discord OAuth with [better-auth](https://better-auth.com/)
- Barebones frontend with basic styling

### Currently working on
- Defining core database schema for users, conversations, and messages

### Planned (for now)
- Basic UI layout for authenticated user page (containing spots for conversations, basic profile, etc.)
- Fundamental real-time direct messaging implementation (backend)
- Basic UI for private DMs (frontend)
- DM requests
- Additional user features (muting, blocking, search, online/offline status, etc.)
- Group chats with 3+ participating members
  
## Technology Stack
BenStack Chat is built with my own tech stack that I created to learn full-stack web development. I wouldn't recommend using it since it's obviously made by a newbie (and probably missing a LOT of things). But, if you're interested to check it out nonetheless, you can find it [here](https://github.com/benstackdev/benstack-v1).
